Tema 01

O que são Sub-redes?

Imagine um prédio enorme com uma sala só. Bagunçado, né? Sub-redes são como dividir esse prédio em andares e salas: mais organização, mais controle e mais segurança.

IP

Endereço IP

É o "RG" de cada aparelho na rede. No IPv4 são 4 números de 0 a 255, tipo 192.168.0.10.

/

Máscara / CIDR

Define quanto da rede é "endereço fixo" e quanto sobra para os aparelhos. O /24 deixa 254 aparelhos.

÷

Por que dividir?

Separar setores (RH, Vendas, TI) evita que um problema numa área derrube a rede inteira.

+

Vantagens

Mais desempenho, menos tráfego desnecessário e isolamento: cada setor no seu "quadrado".

O que cada linha faz

          
Leia junto com os alunos: cada comando acima explicado em português.

        

        
    
          
  • 
            ipconfig /all
            Comando que mostra as configurações de rede do computador (o IP, a máscara e o gateway). É o "raio-x" da conexão.
          
    • 
          
  • 
            IPv4: 192.168.0.10
            É o endereço (o "RG") deste aparelho na rede. Cada máquina tem o seu, e não pode repetir.
          
    • 
          
  • 
            Máscara: 255.255.255.0 (/24)
            Diz qual parte do IP é a rede e qual parte é o aparelho. O /24 reserva espaço para 254 aparelhos.
          
    • 
          
  • 
            Gateway: 192.168.0.1
            É a "porta de saída" da rede — normalmente o roteador. Tudo que vai para a internet passa por aqui.
          
    • 
          
  • 
            calcular-subrede ... --setores 4
            Pede para dividir a rede grande em 4 pedaços menores, um para cada setor da empresa.
          
    • 
          
  • 
            RH / Vendas / TI / Visitas -> /26
            Cada setor virou uma sub-rede separada com 62 aparelhos. Assim um problema no RH não atrapalha as Vendas.
          
    • 
          
  • 
            [ok] rede dividida ✔
            Confirmação de que deu tudo certo: a rede agora está organizada e isolada por setor.

        Tema 02
        
Gestão de Riscos de Segurança

        

          Segurança da informação é proteger o que a empresa tem de valioso. Para isso a gente responde 3 perguntas:
          o que proteger, do que proteger e onde estamos fracos.
        

      


      

        

          Ativo
          
O que tem valor: dados de clientes, sistema, servidor, senha.

        

        
→

        

          Ameaça
          
O que pode causar dano: hacker, vírus, incêndio, funcionário descuidado.

        

        
→

        

          Vulnerabilidade
          
A fraqueza que a ameaça aproveita: senha fraca, sistema desatualizado.

        

      


      

        

          Risco
          =
          Probabilidade
          ×
          Impacto
        

        
Quanto mais provável de acontecer e mais estrago causa, maior o risco. Simples assim.

      


      
      

        

          
          terminal — análise de riscos
        

        

      


      
      

        

          Entenda o console
          
O que cada linha faz

          
Cada passo da análise de risco explicado para você contar aos alunos.

        

        
    
          
  • 
            analisar-riscos --empresa MinhaLoja
            Começa a "varredura" de segurança da empresa, procurando o que pode dar errado.
          
    • 
          
  • 
            [scan] mapeando ativos...
            Está listando tudo que tem valor e precisa ser protegido (o que chamamos de ativos).
          
    • 
          
  • 
            ativo: banco-de-dados-clientes — valor: ALTO
            Encontrou um ativo muito importante: os dados dos clientes. Se vazar, é um problemão.
          
    • 
          
  • 
            ameaca: ransomware — prob: media
            Identificou uma ameaça (vírus que sequestra dados) com chance média de acontecer.
          
    • 
          
  • 
            vuln: backup-desatualizado — grave: SIM
            Achou a vulnerabilidade: o backup está velho. É a "porta aberta" que a ameaça pode usar.
          
    • 
          
  • 
            >> risco: CRITICO (prob x impacto)
            Juntando chance média + estrago alto, o risco final é crítico. Precisa agir logo.
          
    • 
          
  • 
            [acao] backup diario + senha forte + 2FA
            As medidas de mitigação: o que fazer para reduzir o risco (proteger melhor).
          
    • 
          
  • 
            [ok] plano de mitigacao gerado ✔
            Pronto: a empresa agora tem um plano claro para se proteger.
